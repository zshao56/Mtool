# Mtool v1.0.0-beta.5

应用版本：`1.0.0 (6)`。

- 提问框和剪贴板面板底部的功能可用左右方向键选择，回车执行；当前按钮会高亮，超出视野时自动滚动到可见区域。
- 剪贴板面板用上下方向键选择常用词或历史记录，列表会跟随选中项滚动；回车复制或粘贴。按 Esc 关闭。
- 剪贴板面板顶部加入拖动条，可拖动至屏幕上的其他位置。
- 相比 beta.4，微信未公开可验证的输入焦点时，快捷键会先打开提问框，避免普通聊天页面误进剪贴板；可用左方向键选中剪贴板并按回车进入。任何应用中可识别的可编辑输入框仍会直接进入剪贴板。

本预览版使用 ad-hoc 签名。更新后如 macOS 撤销辅助功能信任，请在「隐私与安全性 → 辅助功能」重新允许 Mtool。
