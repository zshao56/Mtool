# Mtool v1.0.0-beta.4

应用版本：`1.0.0 (5)`。

- 剪贴板中的截图直接显示缩略图；点击眼睛按钮可在面板内放大预览，按 Esc 先关闭预览。图片按显示尺寸解码，避免列表加载完整大图。
- 输入框触发主快捷键时先打开剪贴板，列表高度约显示五条，可向下滚动。面板底部保留自由提问、翻译等模式，点击即可切到提问框，提问框也能切回剪贴板。
- 提问框弹出后再次请求输入焦点，打开即可输入；剪贴板搜索框同样自动聚焦。
- 微信没有公开可用焦点时默认显示剪贴板，条目仅复制，防止粘贴到无法确认的位置。安全输入期间不使用此回退。

本预览版使用 ad-hoc 签名。更新后如 macOS 撤销辅助功能信任，请在「隐私与安全性 → 辅助功能」重新允许 Mtool。
