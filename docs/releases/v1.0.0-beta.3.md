# Mtool v1.0.0-beta.3

应用版本：`1.0.0 (4)`。

- 提问框始终显示内置剪贴板入口，包括微信等未公开输入焦点的应用。打开剪贴板后，有可靠的可编辑焦点时才尝试粘贴；否则点击条目会复制，返回原应用后可按 ⌘V。
- 点击其他应用或窗口后，提问框自动收起。提问框和剪贴板改为不透明的系统背景，提高深色终端上的文字对比度。
- 快捷键设置分开录制普通组合键和双击修饰键。双击可识别左/右 Command、左/右 Option；旧配置继续使用任意 Command。普通组合键仍支持 ⌥Space 等，并保留系统热键注册。
- 系统级焦点查询失败时增加前台应用辅助功能焦点查询，提高微信等应用的输入框识别机会。

本预览版使用 ad-hoc 签名，更新后 macOS 可能需要重新授予 Mtool 辅助功能权限。双击修饰键和跨应用焦点识别依赖该权限。跨应用交互仍需在真实桌面验证。
