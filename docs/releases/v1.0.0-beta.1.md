# Mtool v1.0.0-beta.1

科研日常使用的 macOS 菜单栏工具预览版，应用内版本显示为 `1.0.0 (2)`。按自定义快捷键后，选中文字进入科研动作栏，空输入框进入剪贴板与常用词面板，其他情况进入快速搜索框；支持截图复制和 OpenAI 兼容 API。

本次构建在 GitHub Actions macOS runner 上通过 156 项测试、Release 编译和 DMG 打包。DMG 校验和随下载文件提供。

**预览版说明：**应用采用 ad-hoc 签名，尚未经过 Apple 公证。首次打开可能需要在 Finder 中右键点击 `Mtool.app` 并选择“打开”。34 项跨应用桌面验收尚未完成，尤其微信与浏览器输入框识别、跨应用粘贴、快捷键录制和权限流程尚不能视为通过。请将实际使用中发现的问题提交到 [Issues](https://github.com/zshao56/Mtool/issues)。
