# Mtool v1.0.0-beta.2

本版应用内版本为 `1.0.0 (3)`。

- 光标位于可编辑输入框时，主快捷键打开提问框，底部提供内置剪贴板入口。点击后可查看历史和常用词，并沿用原输入框的安全粘贴校验。
- 提问框支持拖动到屏幕上的合适位置；切换到其他应用后仍保持悬停，按 Esc 或再次按主快捷键关闭。
- 底部 AI 模式使用“动作”中的自定义提示词和可选模型；设置按钮直达编辑页。“自由提问”的提示词也可编辑。截图和剪贴板功能由应用本地提供。
- 辅助功能权限在运行中变为可用时，已启用的双击 Command 触发器会自动启动。

构建由 GitHub Actions 完成测试、双架构 Release 编译及 DMG 打包。预览版采用 ad-hoc 签名，未经 Apple 公证。跨应用快捷键、拖动、微信输入框及粘贴仍需在真实桌面逐项验收。
